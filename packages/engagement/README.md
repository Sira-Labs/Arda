# @arda/engagement

The engagement rules of ʿArḍa (ADR-0023), ported from Suffa's `packages/engagement`: the
activity log's shape, XP per event, the level curve, the daily streak with shields, and
ʿArḍa's own daily quests and badges. Pure
TypeScript without I/O; the web app computes Today's numbers with it, the API checks incoming
events with it.
